Who controls post-quantum cryptography

Cryptographic sovereignty is not one thing. This explorer decomposes it into three distinct constructs, indigenous cryptographic capacity (the general, classical-inclusive base), indigenous post-quantum control (the quantum-safe layer only), and external dependency, so a country’s classical strength is never mistaken for control of the post-quantum layer. A country counts as a post-quantum maker only by clearing a strict gate of demonstrated, institutionally sustained post-quantum capability.

Reading the model. Scores are ordinal levels (0–4) coded from cited public evidence; class depends on the maker gate and the ordering of a single creation level, not on arithmetic across the scale. The maker gate requires level 3 on at least one creation layer (primitive design, implementation, or validation) on a sustained institutional basis; classical capability and governance authority alone never qualify. Retention is the fraction of a 4000-draw plausible-state bootstrap over per-cell evidence grades that keeps a country’s maker verdict. Evidence strength is graded H / M / L per cell. This is a companion to the RSCM paper and reflects a purposive sample of documented cryptographic actors, not a global census.

Format guide (what each field means)

Upload a JSON file shaped like the template: a top-level countries array, one object per country. You supply the coded levels (integers 0–4) and the sources; the tool computes R, ICC, Cr, ED, class, type, boundary, and retention, so you never fill those.

FieldTypeMeaning
countrytext, requiredCountry name. Matching an existing name updates it; a new name adds it.
regiontextContinent for the filter (Africa, Asia, Europe, North America, South America, Oceania).
isolatedtrue / falseSet true only for a lone non-institutional academic result; it then cannot clear the maker gate.
R_dimsarray of 5Readiness dimensions, each {name, level 0–4}: strategy, inventory, standards, deployment, workforce.
A_dimsarray of 5Capacity layers, each {name, level 0–4}: authorship, vendor/supply, infrastructure, governance, research/talent.
B_dimsarray of 5Post-quantum control cells B1–B5, each {key, name, level 0–4, ev, why, cite}. B1–B3 (design, implementation, validation) decide the maker gate.
ED_detailobjectExternal dependency, {level 0–4, ev, why, cite}; 0 self-sufficient, 4 fully foreign.
evtextEvidence grade for that cell: High, Medium, or Low (drives the retention bootstrap).
why / citetextOne-line justification and the source URL for that cell.

The maker gate is max(B1,B2,B3) ≥ 3 and not isolated; otherwise a country is capable if ICC ≥ 2, a ready adopter if R ≥ 2, else dependent. Tip: start from Download full database to copy the exact shape of a real country.

About this explorer

RSCM decomposes cryptographic sovereignty into three distinct constructs, indigenous cryptographic capacity, indigenous post-quantum control, and external dependency, and certifies a country as a post-quantum maker only by a strict gate of demonstrated, institutionally sustained capability. This page is the companion to the RSCM paper (arXiv:2609.18477).

How it works

The assessment is produced in two stages. Human coders score each country against a fixed codebook from cited public evidence, recording a level (0–4), an evidence grade, a justification, and a source for every cell. A deterministic pipeline then computes the scores, applies the maker gate, classifies each country, and runs the uncertainty bootstrap. This page only displays those results and, in the Data tab, re-applies the same rules to any entries you add locally.

The three constructs

  • Indigenous cryptographic capacity (ICC) – the general, classical-inclusive base.
  • Indigenous post-quantum control – the quantum-safe layer only, gated for the maker label.
  • External dependency (ED) – how much of the deployed stack is foreign-supplied.

Contributing an update

Anyone can propose a correction, an updated country, or a new one. In the Data & extend tab, download the template, fill it following the codebook (a level 0–4, an evidence grade, a justification, and a source for every cell), and upload it to preview how the rules score it. To have a change reviewed for the published dataset, open a Dataset update issue on the project repository (a guided form asks for the filled template and its sources), or email the filled template to bouke@ieee.org. Every proposed cell must carry a public, citable source.

Companion to the RSCM paper. Use the buttons above the table to download the summary scores or the full per-cell worksheet. Every coded cell lists its level; the evidence grade, justification, and citation are recorded for the post-quantum control layers (B1 to B5) and external dependency, the cells that decide the maker gate and the dependency score. Readiness and general-capacity cells carry a coded level only.
